# vision

Cloudflare R2に保存した画像を、スクリーンセーバーのように設定した範囲の枚数で浮遊表示するWebアプリ。

現在のバージョン: `v0.022`

Vercelへのデプロイを前提とした、Next.js App Router + TypeScript構成のプロジェクトです。

## 開発

```bash
npm install
Copy-Item .env.example .env.local
```

`.env.local` にCloudflare R2の接続情報を設定してから起動します。

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## ディレクトリ構成

```text
src/
  app/
    api/images/route.ts            R2の画像一覧と一時URLを返すAPI
    api/uploads/route.ts           画像保存用の一時URLを発行するAPI
    globals.css                   全体のスタイル
    layout.tsx                    共通レイアウト
    page.tsx                      トップページ
    slideshow.tsx                 複数画像のランダム表示
    updates/page.tsx              更新情報ページ
```

R2バケットが未設定または空の場合は、画面中央に `vision` と表示します。

保存済み画像は設定した範囲からランダムな枚数を同時表示し、1枚ずつ設定した秒数の範囲から別々のタイミングで切り替わります。画像が切り替わるたびに、表示枚数も設定範囲内で1枚ずつランダムに増減します。増える場合は空いている場所へ1枚だけ追加し、減る場合は1枚だけ消すため、ほかの画像の位置や動きは変わりません。画像は全体が見える大きさで、それぞれ異なる位置・大きさ・速さで宙を漂います。配置と移動範囲を分散し、画像同士の重なりは設定した許容値を目安に抑えます。傾きと移動幅を含めた余白を計算し、画像が画面の上下左右からはみ出さないように配置します。

画像の切り替えと表示枚数の増減は、設定した時間の範囲から毎回ランダムに選んだ時間をかけて、徐々に消えたり現れたりする交差表示で行います。初期設定は1.0〜1.5秒です。

トップページ右上の設定ボタンから、常時表示する枚数の最小値と最大値を1〜100枚、画像を入れ替える間隔を1〜3600秒、切替にかける時間を0.1〜10秒、画像の対角線の最小値と最大値を16〜4000px、重なり許容値を0〜100%の範囲で設定できます。設定内容はブラウザに保存されます。

画像サイズは、縦横比を維持したまま左下から右上までの対角線の長さとして扱います。縦長・横長・正方形に近い画像の見た目の大きさの差を抑えます。表示枚数や画面サイズに対して大きすぎる場合だけ、重なりとはみ出しを抑えられる大きさまで自動的に縮小します。従来の長辺設定値は対角線設定としてそのまま引き継ぎます。

トップページ左下の「画像を追加」から、対応画像を1枚25MBまで、複数まとめてR2へ保存できます。

すべての画面で「更新情報」「表示設定」「画像を追加」を通常時は隠し、画面上部をクリックまたはタップしたときだけ8秒間表示します。表示設定を開いている間と画像を追加している間は、自動的に隠れません。

トップページ右下の「更新情報」リンク、または `/updates` で更新履歴を確認できます。
