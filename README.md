# vision

Cloudflare R2に保存した画像を、スクリーンセーバーのように設定した範囲の枚数で浮遊表示するWebアプリ。

現在のバージョン: `v0.013`

Vercelへのデプロイを前提とした、Next.js App Router + TypeScript構成のプロジェクトです。

## 開発

```bash
npm install
Copy-Item .env.example .env.local
```

`.env.local` にCloudflare R2の接続情報を設定してから起動します。

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## ディレクトリ構成

```text
src/
  app/
    api/images/route.ts            R2の画像一覧と一時URLを返すAPI
    api/uploads/route.ts           画像保存用の一時URLを発行するAPI
    globals.css                   全体のスタイル
    layout.tsx                    共通レイアウト
    page.tsx                      トップページ
    slideshow.tsx                 複数画像のランダム表示
    updates/page.tsx              更新情報ページ
```

R2バケットが未設定または空の場合は、画面中央に `vision` と表示します。

保存済み画像は設定した範囲から毎回ランダムな枚数を同時表示し、1枚ずつ設定した秒数の範囲から別々のタイミングで切り替わります。画像は全体が見える大きさで、それぞれ異なる位置・大きさ・速さで宙を漂います。配置と移動範囲を分散し、画像同士が重なる場合も3割程度までに抑えています。傾きと移動幅を含めた余白を計算し、画像が画面の上下左右からはみ出さないように配置します。

トップページ右上の設定ボタンから、常時表示する枚数の最小値と最大値を1〜100枚、画像の切替秒数の最小値と最大値を1〜3600秒、画像の長辺の最小値と最大値を16〜4000pxの範囲で設定できます。設定内容はブラウザに保存されます。

画像サイズは縦横比を維持した長辺の長さとして扱います。縦長画像は高さ、横長画像は横幅が設定値になります。表示枚数や画面サイズに対して大きすぎる場合だけ、重なりとはみ出しを抑えられる大きさまで自動的に縮小します。

トップページ左下の「画像を追加」から、対応画像を1枚25MBまで、複数まとめてR2へ保存できます。

スマホ画面では「更新情報」「表示設定」「画像を追加」を通常時は隠し、画面上部をタップしたときだけ8秒間表示します。表示設定を開いている間と画像を追加している間は、自動的に隠れません。

トップページ右下の「更新情報」リンク、または `/updates` で更新履歴を確認できます。
