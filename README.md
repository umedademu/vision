# vision

画像をスクリーンセーバーのように表示するWebアプリ。

Vercelへのデプロイを前提とした、Next.js App Router + TypeScript構成のプロジェクトです。

## 開発

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## ディレクトリ構成

```text
src/
  app/
    globals.css                   全体のスタイル
    layout.tsx                    共通レイアウト
    page.tsx                      トップページ
```
