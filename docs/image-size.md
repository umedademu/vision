# 画像サイズの設定

v0.032から、表示設定の「画像サイズの基準」で以下の3種類を選択できます。

| 基準 | 最小・最大の数値が指定する長さ |
| --- | --- |
| 対角線 | 画像の左下から右上までの距離（初期値） |
| 長辺 | 画像の横幅と高さのうち長い方 |
| 短辺 | 画像の横幅と高さのうち短い方 |

数値は16〜4000pxで指定し、各画像の表示・入れ替え時に範囲内からランダムに選びます。基準と数値を選んで「反映する」を押すと、初回表示・入れ替え・途中追加のすべてに適用されます。基準変更時に数値の自動換算はしません。

縦横比は維持します。例えば横800・縦600の画像で300pxを指定した場合、対角線基準では240×180px、長辺基準では300×225px、短辺基準では400×300pxになります。

画像管理で切り抜きを保存した画像は、元画像全体ではなく、切り抜いた範囲の幅と高さを基準にサイズを計算します。

表示枚数や重なりを理由に縮小しません。ただし、画像の傾き・漂う幅・画面端の余白を含めて画面内に収まらない場合は、全体が収まるように縮小します。縦長・横長・正方形いずれも実際の縦横比から計算します。

選択した基準と最小・最大値はブラウザに保存され、再読み込み後も維持します。従来の対角線の設定値はそのまま引き継ぎ、基準が未保存または不正な値の場合は「対角線」を使用します。
