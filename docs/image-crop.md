# 画像の切り抜き

v0.033から画像管理ページの各画像に「切り抜き」ボタンを追加しています。

1. 画像の「切り抜き」を押します。
2. 枠の角や辺を動かして範囲を調整します。枠の内側を動かすと範囲の位置を移動できます。マウスとタッチ操作に対応しています。
3. 下部の仕上がりを確認し、「保存する」を押します。

「やめる」では保存しません。「全体を選択」で元画像全体を選び直せます。再編集時は前回の範囲から始まり、保存するまでは表示内容を変更しません。切り抜き以外の画像編集機能はありません。

保存結果は画像管理ページですぐに反映されます。トップページを開き直したときにも反映され、他の端末でも同じ範囲が使われます。すでに開いているトップページは再読み込みしてください。画像サイズの「対角線・長辺・短辺」は切り抜いた部分の縦横比に対して適用します。

元の画像ファイルは変更しません。R2の `.vision-crops/` 以下に、画像ごとの切り抜き範囲と元画像の識別情報を小さなJSONファイルとして保存します。画像は表示時に指定範囲を切り抜くため、画質・透明部分・アニメーションを維持します。画像一覧にはこの保存情報を表示しません。画像を削除したときは、関連する切り抜き情報も削除します。

保存先は `PUT /api/images/crop` です。画像の識別子と、元画像の幅・高さ、切り抜き範囲の位置・幅・高さを受け取ります。範囲外・空の範囲・整数でない座標を拒否し、元画像の存在を確認してから保存します。元画像が同じ名前で別の画像に置き換わった場合、古い切り抜き範囲は適用しません。
